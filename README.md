Para rodar o projeto:

> No **Terminal 1**, execute o Front-End:
> ```
> cd web
> npm i
> npm run dev
> ```

> No **Terminal 2**, execute o Back-End:
> ```
> cd server
> cp .env.sample .env #copiar o env de exemplo
> npm i
> npx prisma generate
> npm run dev
> ```
